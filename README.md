# Pvblicly Landing Page

Landing page for Pvblicly, a remote operations team for busy business owners.

## Publish on GitHub Pages (free)

1. Sign in at github.com and click **New repository**.
2. Name it, for example `pvblicly`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**, drag in `index.html` (and this README), then click **Commit changes**.
4. Go to **Settings → Pages**.
5. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
6. Wait 1–2 minutes. Your live link appears at the top of the Pages screen:
   `https://YOUR-USERNAME.github.io/pvblicly/`

## Before sharing

Open `index.html` in any text editor and search for these placeholders:

- `[CALENDLY LINK]` — your booking link (final call-to-action button)
- `[EMAIL]` — your contact email (footer)
- `[DATE]` — on the sample report card in the hero
- `[Client testimonial — add once approved]` — in the Recent Work section

After editing, upload the new `index.html` to the same repository. GitHub Pages updates automatically.
